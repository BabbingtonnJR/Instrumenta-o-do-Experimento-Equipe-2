# Instrumenta-o-do-Experimento-Equipe-2
Implementação: a lista de requisitos (mínimo 5), critérios de conclusão da tarefa (mínimo 5), exemplos de entrada/saída e restrições, para um problema de programação a ser resolvido em 25min. Deve também ser apresentado um conjunto de testes automatizados (mínimo 3) que serão utilizados para avaliar a dimensão corretude da qualidade.
